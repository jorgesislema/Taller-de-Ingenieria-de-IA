# SECURITY.md - Reglas de Seguridad

## PROTECCIÓN DE DATOS PERSONALES
1. **NUNCA** publiques datos personales sin anonimizar
2. **SIEMPRE** anonimiza datos sensibles antes de analizar
3. **NUNCA** compartas datos personales con servicios externos
4. **DOCUMENTA** todas las fuentes de datos
5. **RESPETA** las regulaciones de privacidad

## SEGURIDAD DE DATOS
1. **Almacenamiento:** Usa ubicaciones seguras para datos sensibles
2. **Acceso:** Implementa control de acceso por roles
3. **Encriptación:** Encripta datos en reposo y en tránsito
4. **Backups:** Mantén backups seguros y encriptados
5. **Retención:** Define políticas de eliminación de datos

## INTEGRIDAD DE DATOS
1. **Origen:** DOCUMENTA todas las fuentes de datos
2. **Calidad:** Verifica completitud, consistencia y exactitud
3. **Transformación:** DOCUMENTA cada transformación aplicada
4. **Backup:** Mantén copias de los datos originales
5. **Auditoría:** Registra todos los cambios realizados

## ÉTICA EN ANÁLISIS
1. **Transparencia:** Sé honesto sobre limitaciones
2. **Objetividad:** Evita sesgos en el análisis
3. **Contexto:** Incluye el contexto del negocio
4. **Responsabilidad:** Asume responsabilidad por los hallazgos
5. **Privacidad:** Respeta la privacidad de los individuos
