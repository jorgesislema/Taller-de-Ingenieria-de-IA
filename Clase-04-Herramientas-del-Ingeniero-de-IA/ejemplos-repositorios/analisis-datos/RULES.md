# RULES.md - Reglas del Proyecto

## Reglas de Análisis
1. **Integridad:** NUNCA uses datos sin verificar su calidad
2. **Metodología:** SIEMPRE documenta la metodología utilizada
3. **Contexto:** INCLUYE el contexto del negocio en cada análisis
4. **Visualización:** PRESENTA resultados de forma gráfica y clara
5. **Recomendaciones:** INCLUYE acciones accionables

## Reglas de Código
1. **Python:** Usa Python 3.8+ con type hints
2. **Estilo:** Sigue PEP 8 (guía de estilo)
3. **Documentación:** Docstrings descriptivos en todas las funciones
4. **Imports:** Ordena (stdlib → third-party → local)
5. **Variables:** Nombres descriptivos, snake_case

## Reglas de Visualización
1. **Etiquetas:** SIEMPRE incluye títulos y etiquetas
2. **Colores:** Usa colores accesibles
3. **Simplicidad:** No sobrecargues los gráficos
4. **Contexto:** Incluye unidades de medida
5. **Exporta:** Guarda gráficos en alta resolución

## Reglas de Datos
1. **Origen:** DOCUMENTA todas las fuentes de datos
2. **Calidad:** Verifica completitud, consistencia y exactitud
3. **Transformación:** DOCUMENTA cada transformación aplicada
4. **Backup:** Mantén copias de los datos originales
5. **Privacidad:** Anonimiza datos personales
