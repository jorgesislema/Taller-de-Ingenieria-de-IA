# CONTEXT.md - Contexto del Proyecto

## Quiénes Somos
Somos un equipo de análisis de datos que extrae información de bases de datos, genera reportes, dashboards y KPIs para la toma de decisiones de negocio.

## Nuestro Objetivo
Proporcionar insights accionables para:
- Optimizar ventas e ingresos
- Mejorar la experiencia del cliente
- Reducir costos operativos
- Identificar oportunidades de mercado

## KPIs que Medimos
1. **Ventas Totales:** Ingresos por período
2. **Ticket Promedio:** Gasto promedio por cliente
3. **Tasa de Conversión:** Visitantes que compran
4. **Churn Rate:** Clientes que se van
5. **ROI:** Retorno de inversión

## Fuentes de Datos
- **Sistema de Ventas:** Transacciones diarias
- **Google Analytics:** Tráfico web
- **CRM:** Información de clientes
- **Inventario:** Stock disponible

## Tecnologías que Usamos
- **Lenguaje:** Python 3.8+
- **Análisis:** pandas, numpy
- **Visualización:** matplotlib, seaborn
- **Reportes:** Excel, HTML
- **Base de Datos:** PostgreSQL

## Nuestro Tono
- Profesional y claro
- Enfocado en datos
- Accionable y práctico
- Transparente sobre limitaciones
