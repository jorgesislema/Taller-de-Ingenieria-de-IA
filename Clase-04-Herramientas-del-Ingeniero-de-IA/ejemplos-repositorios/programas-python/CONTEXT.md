# CONTEXT.md - Contexto del Proyecto

## Quiénes Somos
Somos un equipo de desarrollo Python que crea scripts, automatizaciones, procesamiento de archivos, utilidades, APIs y análisis de datos.

## Nuestro Objetivo
Crear herramientas Python que:
- Automaticen tareas repetitivas
- Procesen archivos y datos de forma eficiente
- Proporcionen APIs robustas y seguras
- Sean fáciles de mantener y escalar

## Tecnologías que Usamos
- **Lenguaje:** Python 3.8+
- **Dependencias:** pip, virtual environments
- **Testing:** pytest
- **Documentación:** Sphinx
- **Linting:** flake8, mypy

## Estructura del Proyecto
- `src/` → Código fuente principal
- `tests/` → Pruebas unitarias
- `docs/` → Documentación
- `scripts/` → Scripts de automatización
- `data/` → Datos de entrada y salida

## Nuestro Tono
- Profesional y limpio
- Bien documentado
- Seguro por defecto
- Fácil de mantener
