# SECURITY.md - Reglas de Seguridad

## PROTECCIÓN DE DATOS PERSONALES
1. **NUNCA** uses datos personales sin consentimiento explícito
2. **SIEMPRE** anonimiza datos sensibles antes de analizar
3. **NUNCA** compartas datos personales con servicios externos
4. **DOCUMENTA** todas las fuentes de datos
5. **RESPETA** las regulaciones de privacidad (GDPR, CCPA)

## SEGURIDAD DE DATOS
1. **Almacenamiento:** Usa ubicaciones seguras para datos sensibles
2. **Acceso:** Implementa control de acceso por roles
3. **Encriptación:** Encripta datos en reposo y en tránsito
4. **Backups:** Mantén backups seguros y encriptados
5. **Retención:** Define políticas de eliminación de datos

## ÉTICA EN IA
1. **Sesgos:** Verifica y corrige sesgos en los datos
2. **Transparencia:** Documenta las suposiciones del modelo
3. **Explicabilidad:** Usa modelos explicables cuando sea posible
4. **Impacto:** Evalúa el impacto social de tus modelos
5. **Responsabilidad:** Asume responsabilidad por los resultados

## AUDITORÍA
1. **Registro:** Documenta cada paso del análisis
2. **Reproducibilidad:** Otros deben poder reproducir tus resultados
3. **Versionado:** Usa Git para controlar versiones del código
4. **Validación:** Valida resultados con expertos del dominio
5. **Monitoreo:** Supervisa el rendimiento de modelos en producción
