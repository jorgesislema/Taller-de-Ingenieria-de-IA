# CONTEXT.md - Contexto del Proyecto

## Quiénes Somos
Somos un equipo de ciencia de datos que análisis estadístico, machine learning, visualización de datos y predicciones para tomar decisiones informadas de negocio.

## Nuestro Objetivo
Extraer información valiosa de datos para:
- Predecir ventas futuras
- Identificar patrones de comportamiento de clientes
- Optimizar procesos de negocio
- Detectar anomalías y fraudes

## Metodología
Seguimos la metodología CRISP-DM:
1. Comprensión del negocio
2. Comprensión de los datos
3. Preparación de los datos
4. Modelado
5. Evaluación
6. Despliegue

## Tecnologías que Usamos
- **Lenguaje:** Python 3.8+
- **Análisis:** pandas, numpy
- **ML:** scikit-learn, xgboost
- **Visualización:** matplotlib, seaborn
- **Notebooks:** Jupyter

## Nuestros Datos
- **Fuentes:** Ventas, marketing, inventario, clientes
- **Período:** 2023-2024
- **Volumen:** Millones de registros
- **Calidad:** 95% completo, 0.1% duplicados
