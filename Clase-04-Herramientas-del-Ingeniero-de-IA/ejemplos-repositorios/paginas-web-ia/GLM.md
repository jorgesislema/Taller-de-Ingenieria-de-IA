# GLM.md - Configuración para ChatGLM (GLM)

## Identidad del Proyecto
Creamos páginas web inteligentes que integran IA para mejorar la experiencia del usuario.

## Reglas de Generación
1. **Código:** Python 3.8+ con type hints
2. **Frontend:** HTML5, CSS3, JavaScript moderno
3. **Documentación:** Comenta en español, usa docstrings
4. **Seguridad:** Nunca expongas API keys en el frontend
5. **Responsive:** Diseño adaptable a todos los dispositivos

## Tecnologías
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** Python 3.8+ con FastAPI
- **IA:** APIs de OpenAI, Claude, modelos open source
- **Base de Datos:** SQLite (desarrollo), PostgreSQL (producción)

## Formato de Salida
- Código en bloques ````python` o ````javascript`
- Explicaciones en texto plano antes y después del código
- Usa markdown para organizar la información

## Restricciones
- NO expongas API keys en el frontend
- NO uses HTTP en producción
- NO omitas validación de entradas
- NO ignores errores de la API de IA
- SIEMPRE implementa fallback para errores
