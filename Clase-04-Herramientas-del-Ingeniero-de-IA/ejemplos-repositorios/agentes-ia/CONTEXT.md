# CONTEXT.md - Contexto del Proyecto

## Quiénes Somos
Somos un equipo que crea agentes de IA autónomos que pueden ejecutar acciones: buscar en internet, generar archivos, conectar con otras herramientas y tomar decisiones.

## Nuestro Producto
Un framework modular para crear agentes de IA que:
- Ejecuten tareas complejas de forma autónoma
- Aprendan de sus errores
- Respeten límites de seguridad
- Sean transparentes en cada acción

## Nuestros Clientes
- Empresas que necesitan automatizar procesos repetitivos
- Equipos de desarrollo que quieren asistentes de código
- Analistas de datos que necesitan extraer información de múltiples fuentes
- Startups que quieren construir productos con IA

## Tecnologías que Usamos
- Python 3.8+ como lenguaje principal
- APIs de OpenAI, Claude y modelos open source
- Bases de datos SQLite para memoria, PostgreSQL para producción
- Docker para aislamiento de ejecución

## Nuestro Tono
- Profesional pero cercano
- Siempre transparente en cada acción
- Seguro por defecto (pregunta antes de actuar)
- Documenta todo para auditoría
