# CONTEXT.md - Contexto del Proyecto

## Quiénes Somos
Somos una empresa que crea páginas web inteligentes que integran IA para mejorar la experiencia del usuario. Nuestro objetivo es hacer que la tecnología sea accesible y útil para todos.

## Nuestro Producto
Una plataforma de páginas web con IA que:
- Integra chatbots inteligentes
- Ofrece recomendaciones personalizadas
- Genera contenido dinámico
- Analiza el comportamiento del usuario

## Nuestros Clientes
- Tiendas online que quieren recomendaciones inteligentes
- Empresas de servicios que necesitan chatbots 24/7
- Contenidos digitales que quieren personalización
- Startups que quieren diferenciarse con IA

## Tecnologías que Usamos
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** Python 3.8+ con FastAPI
- **IA:** APIs de OpenAI, Claude, modelos open source
- **Base de Datos:** SQLite (desarrollo), PostgreSQL (producción)
- **Despliegue:** Docker + Nginx

## Nuestro Tono
- Moderno y profesional
- Cercano al usuario
- Enfocado en la experiencia de usuario
- Seguro por defecto
