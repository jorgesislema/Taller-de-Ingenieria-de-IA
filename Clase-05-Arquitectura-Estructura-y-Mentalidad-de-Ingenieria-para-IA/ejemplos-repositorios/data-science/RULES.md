# RULES.md - Reglas del Proyecto

## Reglas de Código
1. **Python:** Usa Python 3.8+ con type hints
2. **Estilo:** Sigue PEP 8 (guía de estilo de Python)
3. **Documentación:** Docstrings estilo NumPy en todas las funciones
4. **Imports:** Ordena (stdlib → third-party → local)
5. **Variables:** Nombres descriptivos, snake_case

## Reglas de Análisis
1. **Metodología:** Sigue CRISP-DM para cada proyecto
2. **Datos:** NUNCA uses datos de prueba para entrenar
3. **Evaluación:** SIEMPRE usa métricas de evaluación
4. **Validación:** Usa cross-validation cuando sea posible
5. **Reproducibilidad:** Fija semillas aleatorias

## Reglas de Visualización
1. **Etiquetas:** SIEMPRE incluye títulos y etiquetas
2. **Colores:** Usa colores accesibles (daltónicos)
3. **Simplicidad:** No sobrecargues los gráficos
4. **Contexto:** Incluye unidades de medida
5. **Exporta:** Guarda gráficos en alta resolución

## Reglas de Comunicación
1. **Claridad:** Explica hallazgos en lenguaje sencillo
2. **Contexto:** Incluye el contexto del negocio
3. **Limitaciones:** Sé honesto sobre las limitaciones
4. **Recomendaciones:** Incluye acciones accionables
5. **Visualizaciones:** Usa gráficos para comunicar
