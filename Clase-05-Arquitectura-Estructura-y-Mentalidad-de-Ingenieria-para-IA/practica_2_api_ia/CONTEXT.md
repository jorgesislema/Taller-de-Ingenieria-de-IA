# Contexto del Proyecto: Chat con IA via API

## Quienes somos
Somos estudiantes de un taller de Inteligencia Artificial. Estamos aprendiendo a conectar con servicios de IA en la nube usando APIs.

## Que estamos construyendo
Un conjunto de scripts en Python que permiten hacer preguntas a diferentes IAs (Gemini, DeepSeek, GPT, Claude) desde la terminal.

## Nuestro objetivo
- Aprender a usar APIs de IA de forma segura
- Entender como funcionan las llaves de API (.env)
- Manejar entornos virtuales (.venv)
- Conectar con multiples proveedores de IA

## Nuestro tono
- Tecnico pero accesible
- Explicamos con analogias
- Usamos espanol para comentarios y documentacion
- Codigo limpio y bien documentado

## Lo que NO hacemos
- No guardamos llaves en el codigo fuente
- No subimos archivos .env a GitHub
- No usamos librerias innecesarias
- No hacemos scripts que hagan todo a la vez
