# CONTEXT.md - Contexto del Proyecto

## Quiénes Somos
Somos una startup llamada "ChatBot Solutions" que crea chatbots inteligentes para pequeñas y medianas empresas. Nuestro objetivo es automatizar la atención al cliente sin perder el toque humano.

## Nuestro Producto
Un framework modular para crear chatbots que:
- Respondan preguntas frecuentes de clientes
- Programen citas y reservas
- Procesen pedidos básicos
- Escalen a humanos cuando sea necesario

## Nuestros Clientes
- Restaurantes que quieren automatizar reservas
- Tiendas online que necesitan soporte 24/7
- Consultorios médicos para agendar citas
- Empresas de servicios que manejan frequently asked questions

## Tecnologías que Usamos
- Python 3.8+ como lenguaje principal
- APIs de OpenAI, Claude y modelos open source
- Bases de datos SQLite para prototipos, PostgreSQL para producción
- Docker para despliegue

## Nuestro Tono
- Profesional pero cercano
- Siempre positivo y Solution-oriented
- Evitamos jerga técnica innecesaria
- Usamos analogías para explicar conceptos complejos
