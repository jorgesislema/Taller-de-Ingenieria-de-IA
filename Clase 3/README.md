# Clase 3 — La Fábrica Oculta + Herramientas del Ingeniero

> **Duración:** 85 minutos (70 de contenido + 15 de práctica con VSCode/Git)

---

## Objetivos de aprendizaje

Al terminar esta clase, el alumno podrá:

1. Explicar qué es RLHF y por qué la IA necesita humanos para aprender.
2. Identificar los sesgos regionales de la IA (EE.UU., Europa, China).
3. Entender el impacto físico de la IA (energía, agua, GPUs).
4. Conocer los riesgos legales de usar IA (derechos de autor, responsabilidad).
5. Usar VSCode, Git y GitHub para crear su primer repositorio.
