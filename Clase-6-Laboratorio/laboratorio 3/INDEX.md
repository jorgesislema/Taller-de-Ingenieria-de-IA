## 🎯 Flujo de Uso

### Para el Profesor:
1. **Antes:** Leer `NOTAS_PROFESOR.md`
2. **Inicio:** Proyectar `PRESENTACION.md`
3. **Durante:** Guiar con `INSTRUCCIONES.md`
4. **Dudas:** Dirigir a `PROMPTS.md`
5. **Seguridad:** Usar `SEGURIDAD.md`
6. **Final:** Entregar `EVALUACION.md`

### Para el Alumno:
1. **Inicio:** Abrir `INSTRUCCIONES.md`
2. **Fase 1:** Explorar en GitHub
3. **Fase 2:** Clonar y analizar
4. **Fase 3:** Usar prompts de `PROMPTS.md`
5. **Fase 4:** Instalar (opcional)
6. **Final:** Completar `EVALUACION.md`
