## 🎯 El Momento "Wow"

Cuando ejecuten `streamlit run app.py`:
1. Se abre el navegador
2. Ven un dashboard profesional
3. Hacen clic en "Analizar"
4. La IA clasifica cada tweet
5. Aparecen 3 gráficos GRANDES y en VERTICAL

**¡Ellos crearon eso!**

---

## 🔑 Prompts Clave

1. **Lógica**: "Define la lógica paso a paso, sin código"
2. **Estructura**: "Organiza el proyecto con src/ y tests/"
3. **Tests**: "Define métricas de calidad al 90%"
4. **Código**: "Escribe el código con comentarios"

---

## 📊 Los 3 Gráficos

| Gráfico | Qué muestra |
|---------|-------------|
| Pastel | Distribución porcentual |
| Barras | Conteo exacto |
| Línea | Evolución temporal |

**Importante:** GRANDES y en VERTICAL

---

## ⚠️ Errores Comunes

| Error | Solución |
|-------|----------|
| Copiar sin entender | Preguntar "¿por qué?" |
| No ejecutar tests | Siempre probar calidad |
| API key falla | Verificar nombre exacto en .env |
| Streamlit no abre | Verificar instalación |
| Gráficos pequeños | Usar `layout="wide"` |
