# 🏠 Clase 6: Laboratorio de Reconocimiento de Repositorio

## 📂 Estructura del Proyecto de la Clase

```
Clase6_Laboratorio/
│
├── 📄 INSTRUCCIONES.md      ← Archivo principal para el alumno
│   Contiene los pasos detallados del laboratorio paso a paso
│
├── 📄 PROMPTS.md            ← Prompts listos para usar con IA
│   6 prompts copiar-pegar para diferentes momentos
│
├── 📄 GUIA_RAPIDA.md        ← Referencia de comandos y conceptos
│   Tablas resumen de Git, Python y conceptos clave
│
├── 📄 EVALUACION.md         ← Autoevaluación del alumno
│   Plantilla con preguntas y calificación
│
├── 📄 NOTAS_PROFESOR.md     ← Guía para el profesor
│   Cronograma, puntos clave, errores comunes
│
└── 📄 RESUMEN.md            ← Resumen ejecutivo
    Vista rápida de todo el material
```

---

## 🎯 Flujo de Uso

### Para el Profesor:
1. **Antes:** Leer `NOTAS_PROFESOR.md`
2. **Durante:** Usar `INSTRUCCIONES.md` como guía
3. **Si un alumno pregunta:** Dirigirlo a `PROMPTS.md`
4. **Al final:** Entregar `EVALUACION.md` para autoevaluación

### Para el Alumno:
1. **Inicio:** Seguir `INSTRUCCIONES.md` paso a paso
2. **Si necesitas ayuda:** Usar `PROMPTS.md` con la IA
3. **Si olvidas un comando:** Consultar `GUIA_RAPIDA.md`
4. **Final:** Completar `EVALUACION.md`

## 💡 Consejos

1. **No entregar todas las respuestas** - Guiar con preguntas
2. **Dar tiempo** - Que el alumno descubra por sí mismo
3. **Usar la IA como herramienta** - No como sustituto del pensamiento
4. **Verificar comprensión** - Preguntar "¿por qué?" frecuentemente

---

## 📞 Soporte

Si hay problemas con el laboratorio:
1. Verificar Git instalado: `git --version`
2. Verificar Python instalado: `python --version`
3. Verificar conexión a internet
4. Verificar permisos de escritura en la carpeta
